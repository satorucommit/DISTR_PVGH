# Disaster Response Platform

A real-time disaster response web platform connecting citizens, rescue teams, and administrators during natural disasters.

## 🚀 Key Features

- **Citizen Reporting**: Easy incident reporting with GPS location and media uploads
- **AI Verification**: Spam detection and auto-categorization of reports
- **Interactive Maps**: Real-time mapping with color-coded incident markers
- **Admin Dashboard**: Incident management and resource allocation
- **Analytics**: Risk assessment and trend visualization
- **Notifications**: Real-time alerts for emergencies and updates

## 🛠️ Tech Stack

- [Next.js 15](https://nextjs.org/) with App Router
- [TypeScript](https://www.typescriptlang.org/)
- [Tailwind CSS](https://tailwindcss.com/) & [shadcn/ui](https://ui.shadcn.com/)
- [Leaflet.js](https://leafletjs.com/) for mapping
- WebSocket simulation for real-time updates

## 📦 Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## 🎯 Usage

### Citizens
1. Report incidents with the "Report Incident" button
2. View live incidents on the interactive map
3. Check disaster analytics and find safe zones

### Administrators
1. Enable admin mode via the settings icon
2. Manage incidents and allocate resources
3. Send emergency broadcasts
4. Monitor system analytics
